1

المجموعات (Collection)

هي تخزين عناصر متعددة معًا وتخزينها باسم واحد يسمى متغيّر.

List (القائمة)

مجموعة عناصر مخزّنة في متغير واحد، ترتيبها يهم، ولها Index يبدأ من 0.

Dictionary (القاموس)

يُستخدم لتخزين قيمة (Value) معينة في مفتاح (Key) معين — بصيغة key : value.

colorList = ["blue", "red", "green", "black"]
print(colorList[0]) # blue

phoneNumbers = {
  "ali" : "01157082417",
  "ahmed" : "01157082333",
}
print(phoneNumbers["ali"]) # 01157082417
🃏 بطاقات مراجعة سريعة — اضغط للقلب
List
مجموعة عناصر مرتبة، الوصول لها بالـ Index بداية من 0
Dictionary
تخزين Value مرتبط بـ Key، الوصول لها بالمفتاح مش بالترتيب

❓ عايز تطبع "green" من colorList اللي فوق، هتكتب إيه؟

2

التكرار (Iterations)

التكرار (Iteration): تكرار نفس الإجراء عدة مرات حتى الوصول لنقطة نهاية محددة. الحلقة (Loop): رمز يتكرر من بداية العملية إلى نهايتها، ثم يبدأ من جديد.

  • لعمل Loop لازم تعرف: المعلومات التي تعمل عليها، ماذا يحدث في كل تكرار، ومتى تتوقف.
  • لو مفيش شرط توقف واضح، هتقع في Infinite loop.
النوعالاستخدام
for loopلتكرار عملية عدد مرات معيّن، غالبًا للمرور على عناصر Collection.
while loopيستمر التنفيذ طالما الشرط صحيح، ويتوقف فور أن يصبح الشرط خطأ.
for color in colorList:
  print(color)

counter = 5
while counter != 100:
  print(counter)
  counter += ____   # كمّل الكود!

❓ لو الشرط في while loop بقى خطأ فجأة، هيحصل إيه؟

3

استخدام كود خارجي

Module

ملف بايثون يحتوي على تعليمات برمجية (متغيرات أو دوال) — ممكن تكتبه أو تستخدم واحد جاهز.

Library

استخدام وحدات متعددة معًا بحيث تُوزَّع وتُستخدم في مجموعة. مثل: PyTorch, TensorFlow, Pandas.

Framework

مجموعة تعليمات برمجية لا تُستخدم فقط، بل بطريقة معينة محددة. مثل: Django, Dash, CherryPy.

import math
print(math.floor(10.6)) # 10 — تقريب لأصغر عدد صحيح
print(math.ceil(10.6))  # 11 — تقريب لأكبر عدد صحيح

# استيراد دالة من ملف داخل مجلد
from folder_name import file_name

❓ عايز تقرّب الرقم 10.2 لأقرب عدد صحيح أكبر، هتستخدم إيه؟

العمل مع النصوص (Strings)

جمع السلاسل (Concatenation): دمج أكثر من String في String واحدة باستخدام +.

الدالةالوظيفة
.capitalize()جعل أول حرف Capital.
.lower()جعل النص كله صغير.
.find()معرفة موقع كلمة معينة داخل الـ String.
.replace()استبدال كلمة بكلمة أخرى.
.split()تقسيم الـ String إلى أجزاء في List.
name = "Ali"
result = "Welcome " + name
print(result) # Welcome Ali

تخطيط البرنامج

Style Guide

مرجع لطرق كتابة الكود بشكل أفضل ومنظّم وبأداء عالي. أشهرها: PEP 8 للبايثون، وAirbnb للجافاسكريبت.

Pseudocode

وصف بسيط لما تحاول القيام به، قبل كتابة الكود الفعلي — يساعد على تحديد إطار وحل المشكلة دون تشتت.

🃏 بطاقات مراجعة
PEP 8
أشهر Style Guide لكتابة كود بايثون منظم
Pseudocode
خطوة قبل الكود — وصف الحل بلغة بسيطة

تصحيح الأخطاء (Debugging)

Debugging: عملية تحديد وإصلاح الأخطاء في البرنامج. Test Cases: أوامر مصممة لاختبار سيناريو معين والتأكد أن البرنامج يعمل حسب المطلوب.

نوع الخطأمتى يحدث
Syntax Errorعند خرق قواعد اللغة — مثل print(Hello, world) بدون علامات تنصيص.
Runtime Errorعندما لا يستطيع الكمبيوتر تنفيذ الكود — مثل القسمة على صفر.
Semantic Errorعندما تكون المخرجات (Output) غير متوقعة رغم عدم وجود خطأ في اللغة نفسها.

❓ كتبت 10 * (2/0) وحصل Error، ده نوعه إيه؟

البرمجة الكائنية (OOP)

الكود المنظّم بالبرمجة الكائنية تكون أجزاؤه مقسّمة لأجزاء صغيرة تسمى كائنات (Objects)، تتواصل مع بعضها ليعمل البرنامج كوحدة متكاملة. كل Object له:

Attributes (الخصائص)

البيانات التي يحتويها الكائن.

Behavior (السلوك)

ما يستطيع الكائن فعله من أفعال ووظائف.

❓ "لون العين" لكائن إنسان — ده Attribute ولا Behavior؟

مواضيع متقدمة

Drive

يحتوي على البيانات والبرامج، ويظل موجودًا بعد إطفاء الكمبيوتر.

Memory

يتم فيها تشغيل الكود وتخزين النواتج والبيانات المؤقتة — تُمسح عند إعادة التشغيل.

Memory Leak

يحدث عند كتابة كود إدارة الذاكرة بشكل خاطئ، فتزداد المساحة المستخدمة بشكل غير مبرر.

Garbage Collection

عملية إدارة ذاكرة آلية تتعقب العناصر غير المطلوبة وتحذفها.

Algorithm

خطة مكوّنة من خطوات منطقية لحل مشكلة أو تنفيذ فكرة معينة.

🃏 بطاقات مراجعة أخيرة
Garbage Collection
حذف تلقائي للعناصر غير المستخدمة في الذاكرة
Algorithm
خطوات منطقية مرتبة لحل مشكلة معينة
